# KRNL0 Instagram carousels

Ten carousels (1080 x 1350, 4:5), each about a different part of the app, made from the real app footage
and the website's look. Shared tokens and helpers: `_shared/brand.css`. Each post folder has `slide-1.png ...`,
`caption.md` (the Instagram caption + hashtags), its source HTML and capture script.
