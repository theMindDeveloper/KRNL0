Every button in KRNL0 is also a command. ⌨️

KRNL0 has a real Terminal window on your canvas. Type
`krnl todo add "Review the proposal 11:00 1h"` and it's on your Calendar at 11:00.
`krnl habit done "Morning run"` keeps the streak. `krnl pomo start` starts the timer.

Put a few of those lines in a file and your whole morning is one script. Claude Code runs right inside the Terminal window too, so it can use the same commands.
