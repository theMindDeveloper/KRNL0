# v0.8.6 — the final 0.8 release

![KRNL Dock update](../assets/dockupdate.png)

This is the **canonical 0.8 release** of KRNL0. v0.8.0–v0.8.5 were a public packaging-hardening series — each iteration fixed one gotcha that only surfaced in the installed binary. v0.8.6 is the first build that ships every fix together along with the two big merges that close out the 0.8 line:

1. **Full trackpad + macOS support** — proper trackpad gestures everywhere, macOS chrome and signing-ready scaffolding, GPU compositing flags so blur-heavy chrome stays on the GPU path.
2. **Deep Claude Code + terminal integration** — every UI action in KRNL0 now has a matching `krnl` CLI command, so Claude Code running inside the in-app terminal can drive the canvas. `claude/CLAUDE.md` ships with the binary and is loaded automatically when you run `claude` in the terminal.

It's also the first release where the **app installs as `KRNL0`** (capitalised), the Rick Roll tutorial bait actually plays, and every packaged-build bug from earlier 0.8.x patches is closed out.

> **Heads-up:** v0.8.6 supersedes v0.8.0–v0.8.5. Uninstall any earlier 0.8.x build before installing v0.8.6 so the Windows installer doesn't reuse cached binaries.

## What's new since v0.7.0

### KRNL Dock — chassis variants
Mother row lives inside a chassis with three switchable looks: **Synthesizer**, **Telemetry** (default), and **KRNL Dock**. The rack shrinks/grows to the bounding box of visible mothers.

- Telemetry wired up to real KRNL state: mission clock, signal waveform from event log, carrier MHz (nodes·edges), sys pressure (today's completion ratio), downlink (best habit streak), per-mother bays with click-to-pan, AOS/LOS, transmission log
- Light-mode pass on all three chassis; `backdrop-filter` dropped where it darkened rails

### Clock — radial schedule visualisation
Major redesign of how scheduled work is shown on the clock face.

- Train-track lanes per overlapping-task lane (Apple-Fitness-style concentric rings)
- AM/PM toggle bar above the face; 12h-mode toggle
- Glassy liquid-glass arcs with transparent break overlays
- Now-pointer crossing the entire track band; tighter alignment to clock edge
- **Day selector** — view scheduled tasks/habits for *any* day, not just today
- Scheduled habits surface alongside tasks; JetBrains body font

### Decision 28 — Task kind discriminator
Tasks now carry a `kind` of `focus` or `event`.
- **Focus** tasks: Pomodoro splits long `plannedMin` into sessions + breaks; visualised as worm-with-break overlays on clock and calendar
- **Event** tasks: single block, no break, no pomo loop
- POMO/EVENT pill in task header toggles kind; active task auto-clears from the timer if you flip kind mid-session

### Decision 29 — CLI extension surface
The `krnl` CLI now covers the full surface a Claude Code session needs to drive KRNL0 from the terminal — this is what unlocks the deep AI integration.

- Task: `kind`, `note`
- Habit lifecycle: `add`, `toggle`, `mark-done`, `remove`, `archive`
- Frames: `frame.add`, `frame.setSize`, `--near` chain walk
- Analytics: `analytics.totals`, `analytics.streaks`, `analytics.open`
- Log: `log.recent`, `log.tail`
- Theme: `theme.get`
- `claude/CLAUDE.md` rewritten and Skills added so the in-app Claude actually knows how to use these

### Trackpad + macOS support (PR — this release)
- Full trackpad gestures: two-finger scroll pans, pinch-to-zoom
- Mouse-wheel zoom restored on the canvas
- macOS chrome (traffic lights / titlebar) polished
- GPU compositing hints (`enable-zero-copy`, `enable-gpu-rasterization`, Metal on darwin) keep canvas / Orb glow / xterm WebGL on the GPU instead of falling back to software
- Windows `.ico` taskbar icon resolver
- Proximity resize handles on frame/text/image nodes — appear when cursor nears the corner
- Pane context menu (right-click anywhere to add nodes)
- Connectors auto-hide on text/image/frame nodes until hovered

### Analytics — pluggable engine + dashboard
- New `AnalyticsNode` mother with charts (#134)
- Per-day totals, open counters, streaks computed from event log + board state
- Wired into Telemetry chrome cells
- Chart label colours brightened for legibility

### Ambient Radio — favourites + YouTube
- Star YouTube videos to replay without retyping the URL
- Six synthesised Web-Audio presets (Dark, Rain, Fire, Synth, White, Brown) plus a YouTube layer
- **Rick Roll fix (this release):** tutorial bait song now plays. Browsers were blocking unmuted autoplay of the rickroll because it doesn't have the engagement signals YouTube uses to allow it. Fix: start every YT.Player muted (which is always permitted), then `unMute()` 80 ms into `onReady` once playback has started

### Assistant Orb — tutorial flow
- Pomodoro & Tasks tutorial with voice-led choreography
- Quick-action buttons trigger pre-recorded voice flows and camera moves
- Default position bottom-left, clear of the React-Flow Controls column

### Contrast pass
- Dark-on-bright text locked everywhere; calendar legend added
- Habit/Todo body copy fixed on bright backgrounds
- Dark-mode "done" check resolved
- Orphan habit-lane cards auto-clean when source habit is deleted

### App name — KRNL0 (this release)
Installed app, taskbar, window title, and `app.getName()` all return **`KRNL0`** (capitalised) instead of `krnl0`. `package.json`'s `name` field stays `krnl0` per npm convention. The user-data folder (`%APPDATA%/KRNL0/`, `~/Documents/KRNL0/`) is the same physical folder as before on Windows + macOS default filesystems (case-insensitive) — no data migration needed.

## Packaging journey — what 0.8.0 → 0.8.6 fixed

The v0.8 series shipped a new GitHub Actions release pipeline. Each patch release fixed one packaging gotcha that only surfaced once the binaries were on a real installed machine.

| Version | What it fixed |
|---|---|
| **0.8.0** | First CI release pipeline: `macos-14` (arm64 DMG) + `windows-latest` (NSIS .exe). Auto-uploads to draft GitHub Release on `v*` tag push. |
| **0.8.1** | `bin/krnl-init.ps1` (and `krnl.js` / `sys.js`) weren't in the package — `electron-builder` `files` glob missed `bin/`. Terminal opened with `PowerShell -File <missing>.ps1` and errored. Fix: add `bin/**/*` to the glob. |
| **0.8.2** | YouTube embed silently broken. First attempt: serve renderer over custom `krnl-app://` scheme so origin isn't `file://`. *(Insufficient — see 0.8.3.)* |
| **0.8.3** | Real fix for YouTube: spin up a 127.0.0.1-only loopback HTTP server in main process, load renderer at `http://127.0.0.1:<port>/`. YouTube's iframe rejects every non-`http(s)` parent, so a custom scheme wasn't enough; a real HTTP origin works. |
| **0.8.4** | Claude Code inside the terminal didn't know it was in KRNL0 — `claude/CLAUDE.md` was inside `app.asar` (a single archive file), so PowerShell couldn't read it. Fix: `asarUnpack: ["claude/**/*"]` extracts it to a real on-disk sibling; main rewrites `\app.asar\` → `\app.asar.unpacked\` in `$KRNL0_CLAUDE_HOME` before exporting it to the shell. |
| **0.8.5** | GPU compositing flags, Windows `.ico` resolver, plus PRs #151–#155 (terminal renderer stability, claude wrapper picks `.cmd` shim, canvas mouse-wheel zoom restored, cleaner AI-spawned layouts, clock day selector). |
| **0.8.6** | Rick Roll tutorial bait now plays (mute-then-unMute pattern bypasses autoplay block). App installs as `KRNL0` (capitalised). First clean canonical 0.8 build. |

### Other fixes along the way
- `electron` was in `dependencies` — electron-builder rejects that. Moved to `devDependencies`
- Empty repo secrets render as `""`, not unset — electron-builder treated `CSC_LINK=""` as "user supplied a cert" and crashed. Workflow strips empty CSC env vars at runtime
- 8 `exactOptionalPropertyTypes` typecheck errors + 1 dead-code error pre-existing on main were resolved so CI typecheck goes green

## Install

**macOS (Apple Silicon):**
1. Download `KRNL0-0.8.6-arm64.dmg` from the Assets section below
2. Open the DMG, drag KRNL0 to Applications
3. First launch: Right-click → Open (build is unsigned; Gatekeeper prompts once)

**Windows (x64):**
1. Uninstall any older 0.8.x via Settings → Apps
2. Download `KRNL0-Setup-0.8.6.exe`
3. Run the installer. SmartScreen warns on first launch (unsigned build); click "More info" → "Run anyway"

After install, the three things to sanity-check:
- Terminal opens and `claude --version` works
- Ambient Radio → start the Pomodoro tutorial → Rick Roll bait plays
- Inside terminal, ask Claude *"what's krnl0?"* — should answer from the bundled CLAUDE.md

## How to trigger the release pipeline manually

Workflow file: [.github/workflows/release.yml](../../.github/workflows/release.yml). Two ways to start a build.

### A. Push a `v*` tag (normal release flow)

```powershell
git checkout main
git pull
git tag v0.8.7
git push origin v0.8.7
```

The tag push fires the workflow. Mac-arm and Win-x64 jobs run in parallel. On success a **draft GitHub Release** is created with both binaries attached. Edit notes, drop screenshots, click Publish.

### B. Manual dispatch from the GitHub UI

1. Go to **github.com/theMindDeveloper/KRNL0/actions**
2. Click **Release** in the left sidebar
3. Top right: **"Run workflow"** dropdown
4. Pick branch (usually `main`)
5. `draft` input: leave as `true`
6. **Run workflow**

Useful when you want to re-run a build (CI was flaky), or test the pipeline without bumping a version.

### Useful CLI

```powershell
gh run watch                        # interactive picker for live runs
gh run list --workflow=release.yml  # last few runs
gh run view <run-id>                # logs + status
gh run cancel <run-id>              # stop a running build

# Re-tag if v0.8.X ends up on the wrong commit
git tag -d v0.8.7                   # delete locally
git push origin :refs/tags/v0.8.7   # delete on remote
git tag v0.8.7                      # recreate on current HEAD
git push origin v0.8.7              # push
```

### Code signing (later)

The workflow auto-detects signing secrets — no code change needed. Add these in **Settings → Secrets and variables → Actions**:

| Secret | What |
|---|---|
| `MAC_CSC_LINK` | Base64 of your Apple Developer ID `.p12` |
| `MAC_CSC_KEY_PASSWORD` | `.p12` password |
| `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` | For notarisation |
| `WIN_CSC_LINK`, `WIN_CSC_KEY_PASSWORD` | Authenticode `.pfx` + password |

Without these → unsigned builds (current state, what 0.8.6 ships).
