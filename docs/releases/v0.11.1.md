# krnl0 v0.11.1

**Updates work again.** In 0.10.1 and 0.11.0 the update check stopped with *"Couldn't check for updates: Cannot set properties of undefined (setting 'autoDownload')"*, so KRNL0 could not update itself. This version fixes it.

## Install this one by hand

If your KRNL0 is **0.10.1 or 0.11.0**, it can't fetch this update by itself — that is the bug this version fixes. Download the installer below once and run it. It installs over your current KRNL0 and keeps your board.

- **Windows:** **KRNL0-Setup-0.11.1.exe**. Windows may warn about an unrecognised app because the installer isn't code-signed yet. Choose **More info → Run anyway**.

From 0.11.1 on, new versions download in the background again and you see *"KRNL0 … is ready — Restart"*.

Everything that's new in 0.11 (Easy mode and the voiced guide, plans, habits and events on one board, the floating timer) is in the [0.11.0 notes](https://github.com/theMindDeveloper/KRNL0/releases/tag/v0.11.0).

## Fixed

- The update check failed on every Windows install ("Cannot set properties of undefined (setting 'autoDownload')"), so no update could be found, downloaded or installed, and no "new version" note appeared.
