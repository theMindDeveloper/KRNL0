# krnl0 v0.14.0

Your KRNL0 server stays up to date with one click, and installs with one command.

## New

**Your server, up to date in one click.**
- When your server has a new version, a small dot appears on the **saved** badge, and its menu says what is out.
- **Update server** asks for your server password, then shows each step: a backup first, the release checked against its signature, the restart, and back online. If anything fails, the server goes back to the version before by itself, and nothing is lost.
- **Settings › Updates** shows your server too: its version, how it updates, and **Update by itself at night** (off unless you turn it on).
- If the new server needs a newer KRNL0 on your computers, the app says so before you update.
- A server that can't update itself yet shows the one command to run on it, once.

**KRNL0 server in one command, with Docker.**
- Linux and Mac: `curl -fsSL https://github.com/theMindDeveloper/krnl0-server/releases/latest/download/docker.sh | sh`
- Windows (PowerShell): `irm https://github.com/theMindDeveloper/krnl0-server/releases/latest/download/docker.ps1 | iex`
- It finds your address and time zone, starts KRNL0 and its updater, and shows the address and setup code. A server you started with `docker run` moves over with its data, its port and its settings.

## Also new

- The website on a server one version behind keeps everything a newer KRNL0 added. A window it doesn't know yet shows as a quiet card, "Made in a newer KRNL0", instead of a blank box.
- Every KRNL0 release now prepares the matching server release by itself.
- **Command:** `krnl sync server` — your server's version, how it updates, and its last update.
- The *Saved and synced* tutorial shows where server updates appear.
