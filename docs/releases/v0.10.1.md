# krnl0 v0.10.1

**The last time you install KRNL0 by hand.** From this version on, KRNL0 keeps itself up to date.

## New

**Updates arrive by themselves.**
- On Windows, a new version downloads quietly in the background. When it's ready you see *"KRNL0 0.10.2 is ready"* in the bottom-right corner: **Restart** whenever it suits you, or **Later**, and it installs the next time you close KRNL0. Your board, tasks and history stay exactly where they are.
- On macOS you get a note when a new version is out, with a **Download** button.
- The version at the bottom right of the window shows when an update is downloading or ready. Click it to restart into the new version.
- **Settings → Updates** shows your version, when KRNL0 last checked, and a **Check now** button.
- From the terminal: `krnl update status`, `krnl update check`, `krnl update install`, `krnl update open`.

**"KRNL Dock" is now called Nuclear.** Same look, new name, in the frame style picker and on the frame itself. `krnl theme frame nuclear` works too.

## Fixed
- Nodes added from the terminal land in the middle of what you're looking at.

## Install
**This one time**, download the installer below and run it. It installs over your current KRNL0 and keeps your board.
- **Windows:** **KRNL0-Setup-0.10.1.exe**. Windows may warn about an unrecognised app because the installer isn't code-signed yet. Choose **More info → Run anyway**.
- **macOS (Apple Silicon):** **KRNL0-0.10.1-arm64.dmg**. The first time, right-click KRNL0 → **Open**.

After that, new versions come to you.
