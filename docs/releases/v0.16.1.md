# krnl0 v0.16.1

A small update.

## New

- **Start from now.** Drag a plan onto today and it snaps to the time it is now, so it starts from the point you are in. When you add a plan, a small **Now** button next to the time sets today, this minute.
- **KRNL0 is on the Microsoft Store**, for people who prefer to install it from there. Copies from the Store are updated by the Store.

## Fixed

- The "saved · synced" badge at the top no longer jumps between "syncing" and "synced". It stays calm and says **saved · synced**.
