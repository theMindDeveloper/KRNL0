# Code of conduct

KRNL0 is for anyone planning their day. Be the kind of person you'd want to get feedback from.

- Be kind and assume good intent. People here range from first-time GitHub users to engineers.
- Critique the work, not the person.
- No harassment, insults, or discrimination of any kind.
- Keep other people's data private. Never post someone's board, tasks or personal details.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block people who keep doing so. Report problems privately via **Security › Report a vulnerability** or by contacting the maintainer on GitHub.
