# Security

KRNL0 runs on your computer and keeps your board in a local file. It talks to the internet only for the update check (GitHub), and for the embeds, radio and AI features you turn on yourself.

## Reporting a problem

Please **don't open a public issue** for a security problem. Use GitHub's private report instead: **Security › Report a vulnerability** on this repository. You'll get an answer within a week.

Helpful to include: the KRNL0 version, your system, what an attacker could do, and the steps to show it.

## Supported versions

Only the newest release gets fixes. Installed apps on Windows update themselves; on macOS, download the newest release.
